# Setup Instructions

## Prerequisites

Before setting up this project, ensure you have the following installed:

- **Node.js**: Version 18.x or higher
- **npm**: Comes with Node.js
- **Task**: Taskfile.dev task runner ([installation instructions](https://taskfile.dev/installation/))

## Setting Up From Scratch

Follow these steps to set up the project from the source code:

### 1. Clone or Navigate to the Repository

```bash
cd /path/to/calc
```

### 2. Install Dependencies

All dependencies are managed through the Taskfile:

```bash
task install
```

This command will:
- Install all npm packages from `package.json`
- Create `node_modules/` directory
- Generate `package-lock.json`

### 3. Prepare Test Data

Ensure you have an XLSX file in the `./tmp` directory:

```bash
# Create tmp directory if it doesn't exist
mkdir -p tmp

# Place your XLSX file in the tmp directory
# The file should contain an "Entry List" sheet with LMP3, GT4, and GT3 sections
cp /path/to/your/spreadsheet.xlsx ./tmp/
```

**Required XLSX Structure:**
- File must have a sheet named "Entry List"
- Entry List sheet should contain three side-by-side entry lists:
  - LMP3 entries (columns B-N)
  - GT4 entries (columns S-AG)
  - GT3 entries (columns AI-AU)
- Each section should have columns for: Car #, Name, iRacing #, Class, LP, Protests, Car (GT3/GT4 only), Car Swap

### 4. Build the Project

Compile the TypeScript source code:

```bash
task build
```

This command will:
- Compile all `.ts` and `.tsx` files from `src/` to JavaScript
- Generate output in `dist/` directory
- Create source maps and type declarations

### 5. Run the Application

```bash
task run
```

Or use the development mode (builds and runs in one step):

```bash
task dev
```

## Available Taskfile Commands

### Core Commands

- `task install` - Install all project dependencies
- `task build` - Compile TypeScript to JavaScript
- `task run` - Run the compiled CLI application
- `task dev` - Build and run in one command (development mode)

### Maintenance Commands

- `task clean` - Remove all dependencies and build artifacts
  - Deletes `node_modules/`
  - Deletes `dist/`
  - Deletes `package-lock.json`
- `task lint` - Run ESLint on source code
- `task test` - Run tests (placeholder in v1)

## Troubleshooting

### "No XLSX file found in ./tmp directory"

**Problem**: The application cannot find an XLSX file to load.

**Solution**:
1. Verify that the `./tmp` directory exists
2. Ensure there's at least one `.xlsx` file in the directory
3. Check file permissions (readable by your user)

### Build Errors

**Problem**: TypeScript compilation fails.

**Solution**:
1. Ensure all dependencies are installed: `task install`
2. Check Node.js version: `node --version` (should be 18.x or higher)
3. Try cleaning and rebuilding: `task clean && task install && task build`

### Module Not Found Errors

**Problem**: Runtime errors about missing modules.

**Solution**:
1. Rebuild the project: `task build`
2. Check that `dist/` directory exists and contains compiled `.js` files
3. Verify all imports use `.js` extensions (TypeScript requires explicit extensions for ES modules)

### Ink/React Rendering Issues

**Problem**: Terminal display is garbled or broken.

**Solution**:
1. Ensure your terminal supports ANSI escape codes
2. Try resizing the terminal window
3. Use a modern terminal emulator (iTerm2, Windows Terminal, GNOME Terminal, etc.)
